# نسخة الموقع الحي

مرآة للملفات الثابتة المنشورة فعلياً على `https://speakozy.web.app/`، تم تنزيلها في 18 نوفمبر 2026 من Firebase Hosting.

هذه هي النسخة التي يراها الزوار الآن. تختلف عن مجلد `public/` الموجود في جذر المستودع: أسماء ملفات الـ assets فيه قديمة (`main-BsVkuyA8.js` مثلاً) بينما الموقع الحي يستخدم `main-DRpoTQXw.js`.

الملفات:

- `index.html`, `login.html`, `system-preview.html`
- `assets/` — حزم JavaScript وCSS المنشورة
- `manifest.webmanifest`, `sw.js`, `icons/`

مصدر التحديث الحقيقي هو Google Cloud Shell (`~/speakozy-site/public/`)، وليس هذه النسخة المحلية. لأي تعديل، راجع `DEPLOY-STEPS.txt` و `speakozyui/FIREBASE-DEPLOY.md`.
